# Shoutzor

Shoutzor is a media voting system perfect for events such as lan-parties!\
Comes with autoDJ to keep requests going when no requests have been added by users.

## Repositories Overview

| Repository                                         | Description |
|----------------------------------------------------|-------------|
| [Shoutzor](https://github.com/Shoutz0r/Shoutz0r)   | The Shoutzor repository, offering information on how to install Shoutzor |
| [Frontend](https://github.com/Shoutz0r/frontend)   | The frontend code of Shoutzor |
| [Backend](https://github.com/Shoutz0r/backend)     | The backend code of Shoutzor |
| [player](https://github.com/Shoutz0r/player)       | The stream generator, interacts with Shoutzor for playing requests and providing the output stream |
| [Storybook](https://github.com/Shoutz0r/storybook) | Contains storybook stories for the components used in the frontend |
| [website](https://github.com/Shoutz0r/website)     | Github Pages repository for the Shoutzor website |
| [.github](https://github.com/Shoutz0r/.github)     | Special repository that hosts the readme you're reading right now |
